# Toddler Games

A collection of playful, child-friendly applications designed to make learning and play more engaging.

## Applications

| Application | Description | Documentation |
|---|---|---|
| Calm Car Game | A simple, interactive car game for young children. | [README](apps/calm-car-game/README.md) |
| ABC Adventure | An interactive alphabet-learning game with illustrations, pronunciation, and object-identification activities. | [README](apps/abc-adventure/README.md) |
| Number Game | Coming soon. | — |

## Getting started

### Prerequisites

- Node.js
- Yarn Classic (1.x)
- Git

Install dependencies from the repository root:

```bash
yarn install
```
